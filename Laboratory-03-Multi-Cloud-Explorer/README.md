## Checkpoint 7 - Linux Investigation

### Linux Server Investigation

The Linux server was investigated using the KillerCoda Playground. The server is running Ubuntu 24.04.4 LTS with an Intel Xeon E312xx processor and 1 CPU. It has 1.9 GiB of total memory and a 19 GiB root disk with 13 GiB of available space.

The following commands were used:

* `cat /etc/os-release` - identifies the operating system.
* `lscpu` - displays CPU information.
* `free -h` - displays memory information.
* `df -h` - displays disk space information.

### Cloud Services That Could Host the Linux Server

If this Linux server were migrated to the cloud, it could be hosted using **Amazon EC2** in AWS, **Azure Virtual Machines** in Microsoft Azure, or **Google Compute Engine** in Google Cloud Platform. These services provide virtual machines that can run Linux operating systems. Therefore, any of the three cloud providers could be used to host a similar Linux server in the cloud.
