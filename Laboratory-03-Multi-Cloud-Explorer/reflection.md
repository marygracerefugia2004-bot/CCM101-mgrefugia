# Checkpoint 8 - Reflection

## 1. Which cloud platform impressed you most?

The cloud platform that impressed me the most is AWS. I like it because it has many services that can be used for different cloud computing needs. I also found it useful for organizations that need scalable cloud resources.

## 2. What similarities exist among AWS, Azure, and GCP?

AWS, Azure, and GCP all provide similar basic cloud services. They offer computing, storage, networking, databases, and identity management. They also allow users to access cloud resources without having to manage all the physical hardware themselves.

## 3. How do business requirements influence cloud platform selection?

Business requirements help determine which cloud platform is the best choice for an organization. Factors such as budget, existing technologies, performance, scalability, and business goals should be considered. For example, a company using Microsoft technologies may choose Azure, while an AI-focused company may prefer GCP.

## 4. What did you learn from acting as a Cloud Solutions Consultant?

I learned that choosing a cloud provider requires more than just knowing its services. A Cloud Solutions Consultant needs to understand the client's needs and match them with the right cloud solutions. This activity helped me practice making recommendations based on real business situations.

## 5. How has your GitHub portfolio improved?

My GitHub portfolio improved because I was able to organize my cloud computing research and laboratory activities in one repository. I learned how to create and manage Markdown files and organize screenshots as evidence. It also gives me a better way to present my technical work.
