# Azure Research

## 1. Brief Overview

Microsoft Azure is Microsoft's cloud computing platform for building, running, and managing applications and services. It provides cloud services for computing, storage, networking, databases, analytics, artificial intelligence, security, and other business needs.

## 2. Global Infrastructure

Azure has a global infrastructure made up of regions, datacenters, geographies, and Availability Zones. Azure regions are geographic locations where Azure services are deployed, while Availability Zones are physically separate locations within a region designed to improve availability and resilience. Azure's global network helps organizations deploy applications closer to users and support data residency and low-latency requirements.

## 3. Cloud Management Console

The Azure portal is a web-based unified console used to create, manage, and monitor Azure resources. It provides a graphical interface where users can access services, create resources, manage subscriptions, view dashboards, and monitor cloud deployments.

## 4. Four Core Services

### Azure Virtual Machines

Azure Virtual Machines provides scalable computing resources that allow organizations to run Windows or Linux virtual machines in the cloud.

### Azure Blob Storage

Azure Blob Storage is an object storage service designed to store large amounts of unstructured data such as documents, images, videos, and backups.

### Azure Virtual Network

Azure Virtual Network enables Azure resources to communicate securely with each other, the internet, and on-premises networks.

### Microsoft Entra ID

Microsoft Entra ID is Microsoft's cloud-based identity and access management service. It helps organizations manage users, identities, authentication, and access to applications and resources.

## 5. Three Advantages

1. **Microsoft Integration** – Azure works closely with Microsoft technologies and services, making it useful for organizations already using Microsoft products.
2. **Global Scale and Resilience** – Azure provides a large global infrastructure that supports availability, disaster recovery, and low-latency application deployment.
3. **Hybrid and Multicloud Support** – Azure supports organizations that operate across on-premises environments, multiple clouds, and edge locations.

## 6. Typical Enterprise Use Cases

Azure is commonly used by enterprises for application hosting, cloud migration, data storage, databases, artificial intelligence and machine learning, analytics, hybrid cloud environments, and business applications. It is particularly useful for organizations that already use Microsoft technologies and need to integrate their existing systems with cloud services.
