## 2. Comparison Questions

### 1. Which cloud provider offers the broadest range of services?

**AWS offers the broadest range of cloud services among the three major providers.** It provides services for computing, storage, databases, networking, security, analytics, machine learning, and many other cloud requirements.

### 2. Which provider best integrates with Microsoft technologies?

**Microsoft Azure best integrates with Microsoft technologies.** It works closely with services such as Windows Server, Microsoft 365, Active Directory, and other Microsoft enterprise solutions.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

**Google Cloud Platform is especially strong in Artificial Intelligence, machine learning, and Kubernetes.** Google developed Kubernetes and provides services and tools that support AI, machine learning, data analytics, and cloud-native application development.

### 4. Which cloud platform would you personally choose and why?

**I would personally choose AWS because it offers a wide range of cloud services and supports many different types of applications and organizations.** Its broad selection of compute, storage, networking, security, and other services would give me more options when building and expanding cloud-based projects.
