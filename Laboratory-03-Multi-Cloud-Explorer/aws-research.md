# AWS Research

## 1. Brief Overview

Amazon Web Services (AWS) is a cloud computing platform launched in 2006. It provides a broad range of cloud services such as computing, storage, databases, networking, analytics, security, and application development. AWS allows organizations to access cloud resources on demand and scale their infrastructure according to their needs.

## 2. Global Infrastructure

AWS operates a global cloud infrastructure made up of Regions and Availability Zones. AWS Regions are geographic areas where AWS provides cloud services, while Availability Zones are separate locations within a Region designed to provide greater reliability and resilience. AWS also provides infrastructure options such as Local Zones, AWS Outposts, and CloudFront for different workload and location requirements.

## 3. Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services and resources. It provides centralized access to AWS service consoles, service search, account and billing information, notifications, and resource management. Users can also use the console to monitor and manage their cloud applications and services.

## 4. Four Core Services

### Amazon EC2
Amazon Elastic Compute Cloud (Amazon EC2) provides resizable computing capacity in the AWS Cloud. It allows users to launch and manage virtual servers.

### Amazon S3
Amazon Simple Storage Service (Amazon S3) is an object storage service used to store and retrieve data from anywhere through the internet.

### Amazon RDS
Amazon Relational Database Service (Amazon RDS) makes it easier to set up, operate, and scale relational databases in the cloud.

### Amazon VPC
Amazon Virtual Private Cloud (Amazon VPC) allows users to create and manage a logically isolated virtual network for AWS resources.

## 5. Three Advantages

1. **Scalability** – AWS allows organizations to scale computing and other cloud resources according to changing business requirements.
2. **Global Infrastructure** – AWS provides a worldwide infrastructure that helps organizations deploy applications closer to their users.
3. **Cost Efficiency** – AWS uses a pay-as-you-go approach, allowing organizations to avoid large upfront infrastructure expenses.

## 6. Typical Enterprise Use Cases

AWS is commonly used by enterprises for application hosting, data storage, databases, analytics, artificial intelligence and machine learning, migration and modernization, and hybrid cloud environments. Its scalable infrastructure allows organizations to support business growth while managing computing, storage, networking, and application requirements.
