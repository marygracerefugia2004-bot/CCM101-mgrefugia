## Linux Commands Used

* `sudo useradd` – Creates a new user account on the Linux system.
* `su` – Switches the current terminal session to another user account.
* `whoami` – Displays the username of the user currently logged into the terminal.
* `pwd` – Prints the absolute path of the current working directory.
* `hostname` – Displays the network name assigned to the system.
* `sudo` – Executes a command with administrative privileges.
* `free` – Displays the total, used, and available system memory.
* `df` – Shows the available and used disk space.
* `cat` – Displays the contents of a text file in the terminal.
* `uname` – Displays system and kernel information.
* `lscpu` – Displays detailed CPU information.
* `ls` – Lists files and folders inside the current directory.
* `mkdir` – Creates a new directory or folder.
* `cd` – Changes the current working directory.
* `touch` – Creates a new empty file.
* `nano` – Opens a text editor used to create or edit files in the terminal.
