This activity helped me understand Linux better because I was able to use it myself. At first, I was confused with some commands, and I was not used to working in the terminal.

As I continued the checkpoints, I became more familiar with navigating folders, creating files, and checking system information. It was frustrating, but it also helped me become more familiar with the steps and commands.

I also learned that I need to be careful when typing commands because even a small mistake can cause an error. This activity gave me a better understanding of basic Linux commands and made me more comfortable using the terminal.
