# Security Audit Report

## 1. The Principle of Least Privilege (PoLP)

**Question: What is the Principle of Least Privilege (PoLP), and why is it important for cloud user accounts?**

The Principle of Least Privilege means giving users only the permissions they need to do their tasks. In cloud computing, this helps protect accounts and important resources because users cannot access things they do not need.

## 2. Attack Surface

**Question: What does the term Attack Surface mean when applied to a virtual machine?**

The attack surface refers to the possible ways an attacker could try to access or harm a virtual machine. Open ports, running services, and unnecessary applications can create more opportunities for attacks.

## 3. Default Deny Policy

**Question: Why is it safer to block all traffic by default rather than trying to block specific hackers individually?**

A Default Deny policy blocks incoming network traffic unless it is specifically allowed by a firewall rule. It is safer because it limits access to approved services instead of requiring administrators to identify and block every possible attacker.

## Conclusion

These security practices help reduce unnecessary access and protect a server. Allowing only the required services makes the system easier to manage and safer to use.
