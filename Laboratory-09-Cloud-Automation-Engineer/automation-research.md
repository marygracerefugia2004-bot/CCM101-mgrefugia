# Automation Research

## 1. Bash Script

 What is it, and what does the `#!/bin/bash` line (the shebang) do at the top of a file?

A Bash script is a file containing commands that Linux can run automatically. The `#!/bin/bash` line tells the system to use Bash to execute the script.

## 2. Variables

 Why do programmers use variables (like `$BACKUP_DIR`) instead of typing out the exact folder path every time?

Variables store values that can be reused in a script. They make the script easier to read and update because we only need to change the value in one place.

## 3. Cron Job

 What is a cron job in Linux, and why is it essential for cloud operations?

 A cron job is a scheduled task that runs commands automatically at a set time. It is useful in cloud operations because tasks such as backups can run regularly without someone needing to start them manually.
