# Cloud Infrastructure Components

## 1. Compute Resources

**Purpose:** Compute resources are used to run programs and tasks.

**Importance in cloud computing:** They provide the processing power needed by applications.

**KillerCoda:** The server has an Intel Xeon E312xx CPU and 1 CPU core.

## 2. Storage Resources

**Purpose:** Storage is used to save files, programs, and data.

**Importance in cloud computing:** It keeps data available for users and applications.

**KillerCoda:** The server has a 19G disk, with `/dev/vda1` mounted on `/`.

## 3. Networking Resources

**Purpose:** Networking allows computers and servers to communicate.

**Importance in cloud computing:** It connects users, servers, and cloud services.

**KillerCoda:** The server has the IP addresses `172.30.1.2` and `172.17.0.1`.

## 4. Operating System

**Purpose:** The operating system manages the computer and its resources.

**Importance in cloud computing:** It provides the system needed to run applications and services.

**KillerCoda:** The server uses Ubuntu 24.04.4 LTS with the `6.8.0-138-generic` kernel.
