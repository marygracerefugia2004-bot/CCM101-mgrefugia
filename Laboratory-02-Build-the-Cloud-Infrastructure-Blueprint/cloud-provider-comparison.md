# Cloud Provider Comparison

## Cloud Infrastructure Services

| Infrastructure Component             | AWS        | Microsoft Azure        | Google Cloud Platform |
| ------------------------------------ | ---------- | ---------------------- | --------------------- |
| Compute                              | Amazon EC2 | Azure Virtual Machines | Compute Engine        |
| Storage                              | Amazon S3  | Azure Blob Storage     | Cloud Storage         |
| Networking                           | Amazon VPC | Azure Virtual Network  | Google Cloud VPC      |
| Identity and Access Management (IAM) | AWS IAM    | Microsoft Entra ID     | Cloud IAM             |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.

For me, **AWS offers the broadest range of services** because it provides many services for computing, storage, networking, security, databases, and other cloud needs. It can support different types of users and organizations.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend **Microsoft Azure** because it works well with Microsoft products and services. It is a good choice for organizations that already use Microsoft tools.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

**Google Cloud Platform** is widely known for its AI and Machine Learning services. It also offers **Google Kubernetes Engine (GKE)** for managing Kubernetes applications.

### 4. What similarities did you observe among the three cloud providers?

I observed that **AWS, Microsoft Azure, and Google Cloud** all provide important cloud services such as compute, storage, networking, and identity management. Even though their service names are different, they offer similar functions for users and organizations.
