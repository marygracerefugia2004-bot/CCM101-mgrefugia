# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think networking is the most important component because it allows users, servers, and services to communicate with each other. Without networking, users would not be able to properly access cloud applications and services.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing an operating system where applications and services can run. It also allows users to manage the server and check its resources using different Linux commands.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it helps us understand and organize the resources needed for the system. It can also help prevent mistakes and make it easier to check or fix problems later.
